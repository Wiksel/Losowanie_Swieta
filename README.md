# Losowanie prezentów 🎁

Świąteczne losowanie prezentów: wpisz osoby, ustaw wykluczenia i tematykę, wylosuj, wyślij każdemu jego link.

- Strona: https://wiksel.github.io/Losowanie_Swieta/
- Bez logowania i bez serwera. Wynik danej osoby jest zapisany tylko w jej linku (po `#`), więc nie trafia nigdzie poza przeglądarkę.
